# LocalTube

LocalTube lets you browse your private audio and video library with a YouTube-like experience. Media, accounts, settings, thumbnails, and history remain local to the browser and device. A library may also be served to devices on the same trusted network when running the app from a local host.

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:8080` in Chrome or Edge, create a local account, then add a library root from Settings.

## Main features

- Local folder access through the File System Access API.
- Folders as channels and nested folders as playlists.
- Local encrypted profiles, preferences, history, favorites, and watch-later lists.
- Responsive Arabic RTL and English LTR interface.
- Advanced player with resume, subtitles, speeds, PiP, theater, fullscreen, and sequential autoplay.
- On-device fallback conversion for legacy media formats.
- Locally cached thumbnails and metadata.
