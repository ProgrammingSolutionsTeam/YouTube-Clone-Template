# خطة إنهاء ملاحظات LocalTube

## النتيجة المطلوبة
تثبيت هوية **LocalTube**، تحسين سرعة التصفح، جعل الصور المصغرة تظهر وتُحفظ محليًا، وتصحيح دورة تشغيل الملفات والتنقل وميزة PiP، مع إزالة اعتماد التشغيل على الروابط الخارجية وإضافة دليل عربي/إنجليزي.

## التنفيذ

### 1. الصور المصغرة والأداء
- إضافة طابور مركزي منخفض الأولوية لتوليد الصور المصغرة للعناصر الظاهرة فقط، بعدد مهام متزامنة محدود حتى لا تتجمد الواجهة.
- عرض الصورة المحفوظة فورًا من IndexedDB، وتوليد الصورة الناقصة تلقائيًا ثم تحديث البطاقة دون إعادة فهرسة أو فتح الفيديو.
- إلغاء مهام المعاينة والمؤقتات وملفات `blob:` عند مغادرة البطاقة/الصفحة، وتعطيل معاينة hover على أجهزة اللمس.
- تقليل الأعمال الثقيلة أثناء التصفح: منع فتح ملفات فيديو متعددة للمعاينة، تنظيف عنصر الفيديو وموارده عند التبديل، وعدم تشغيل فحوص metadata متوازية بلا حدود.

### 2. صفحة المشغل والتنقل الصحيح
- إضافة زر رجوع واضح أعلى صفحة المشغل: يعود لسجل المتصفح عند وجوده، وإلا يعود إلى المجلد الحالي.
- بناء قائمة تشغيل مرتبة تشمل الملف الحالي بدل قائمة `siblings` غير المرتبة؛ حساب السابق والتالي بحسب موضع الملف الحقيقي.
- عدم الالتفاف بين ملفين: السابق يُعطّل عند البداية، التالي يُعطّل عند النهاية، والتشغيل التلقائي يتوقف عند آخر ملف.
- إبقاء نفس ترتيب المجلد عند التنقل اليدوي أو التلقائي وعدم القفز إلى مجلد القناة الأم.
- عرض الملف الحالي داخل قائمة التشغيل بعلامة تشغيل/تمييز واضح و`aria-current`، مع إمكانية اختيار أي ملف من القائمة مباشرة.

### 3. إصلاح PiP وتعدد التشغيل
- قبل تغيير الملف: إيقاف الفيديو القديم، الخروج من PiP إن كان العنصر القديم داخله، فصل `src`، استدعاء `load()`، ثم تحرير Object URL.
- ضمان وجود جلسة تشغيل واحدة فقط داخل التطبيق، وتنظيف محرك التحويل والـMediaSource والمؤقتات عند مغادرة المشغل.
- ربط حالة PiP بأحداث الدخول والخروج الفعلية حتى لا تبقى واجهة المشغل بحالة قديمة.

### 4. LocalTube والعمل المحلي
- استبدال الاسم القديم في الواجهة، بيانات الصفحة، النصوص، وREADME باسم **LocalTube**.
- استخدام الوصف المطلوب بالعربية وترجمته الإنجليزية في بيانات الصفحة والتوثيق.
- إزالة Google Fonts واستخدام خط نظام محلي موثوق حتى لا يحتاج بدء التطبيق إلى الإنترنت.
- نقل ملفات تشغيل FFmpeg/WASM التي تُطلب حاليًا من `unpkg` إلى ملفات محلية تحت `public/assets/scripts` وتعديل المحرك ليحمّلها محليًا فقط.
- إنشاء الهيكل المطلوب:
  - `public/assets/icons`
  - `public/assets/images`
  - `public/assets/css`
  - `public/assets/js`
  - `public/assets/scripts`
  - `public/assets/others`
- إبقاء ملفات المصدر التي يجمعها Vite داخل `src`؛ مجلدات `public/assets` مخصصة فقط للموارد الثابتة المطلوبة وقت التشغيل.

### 5. التوثيق والتحقق
- إعادة كتابة README باسم LocalTube دون صور أو شارات خارجية.
- إنشاء `DOCUMENTATION.md` بدليل متسلسل كامل بالعربية ثم الإنجليزية: المتطلبات، التثبيت، التشغيل، إنشاء الحساب، إضافة Root، الفهرسة، التصفح، المشغل، الصيغ القديمة، الخصوصية، النسخ الاحتياطي، واستكشاف الأخطاء.
- التحقق باختبارات موجهة لمنطق السابق/التالي ونهاية القائمة، ثم فحص فعلي للواجهة على الهاتف وسطح المكتب والتأكد من عدم وجود طلبات شبكة خارجية أثناء التشغيل.

## تفاصيل تقنية
- سيُفصل منطق قائمة التشغيل في دوال نقية قابلة للاختبار بدل اختيار أول/آخر عنصر من `siblings`.
- الصور المصغرة ستبقى Blobs محلية في IndexedDB ولن تُرفع إلى أي خادم.
- ملفات FFmpeg الأساسية ستكون ضمن حزمة التطبيق المحلية؛ تشغيل الصيغ القديمة يظل داخل جهاز المستخدم.
